# Google Translate Text-to-Speech Downloader

Live demo: https://text-to-speech-downloader.web.app/

A small web app (built with React) that lets you convert text to speech using Google Translate's TTS and download the generated audio. The UI supports desktop and mobile and provides a quick way to obtain TTS audio files for short text snippets.

## Features

- Convert text to speech using Google Translate TTS
- Download generated audio files
- Simple, mobile-friendly UI

> Note: This project uses the Google Translate web TTS endpoints — check the source code for exact implementation details and limitations.

## Tech stack

- React (JavaScript)
- HTML, CSS

## Run locally

1. Clone the repository:

   git clone https://github.com/eosrmg/google.translate.downloader.git

2. Install dependencies:

   npm install

3. Start the development server:

   npm start

4. Build for production:

   npm run build

If the project uses yarn, substitute `yarn` for `npm`.
